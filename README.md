# Tank Game 🎮

A 3D tank game built with Three.js featuring a custom tank model.

## Features
- 3D tank with rotating turret and cannon
- WASD movement controls
- Mouse aiming for turret
- Click to fire projectiles
- Physics with gravity and jumping
- Dynamic camera following
- Shadow effects

## Controls
- **W/A/S/D** - Move tank (forward/left/back/right)
- **Mouse** - Aim turret
- **Click** - Fire cannon
- **Space** - Jump

## How to Play
1. Open `index.html` in a web browser
2. Use WASD to navigate the tank
3. Move your mouse to aim the turret
4. Click to fire projectiles

## Technologies
- Three.js for 3D rendering
- JavaScript for game logic
- HTML5 Canvas
